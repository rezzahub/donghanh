Brief & Primitives

The JSX primitives that make up the agent's HUD.

Every operation returns a <Brief>, a JSX tree that serves as the agent's heads-up display. The framework renders it differently per target.

Primitives

<Action>

A suggested next operation, a tool hint for the agent.

tsxCopy
<Action
  operation="record-settlement"
  label="Settle debt"
  variables={{ groupId: "abc", amount: 50000 }}
/>
